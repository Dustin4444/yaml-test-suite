YAML Test Suite

Comprehensive Test Suite for YAML

Overview

This repository contains data for testing the correctness of YAML processors.

The types of data include:

  • Metadata about the test (Name, Tags, Description)
  • Input YAML
  • Canonical output YAML
  • Matching JSON
  • Token stream notation
  • Event stream notation
  • Error data

Resources

  • YAML Test Matrix
  • Test Results from 15 Different Parsers
  • GitHub Repository

Usage

The tests are available in 2 forms. Files in the src directory encode all the data for YAML using YAML. The data from these tests is also available in a form where each test has its own directory.

For the latest data release, visit: https://github.com/yaml/yaml-test-suite/releases

Libraries Using This Test Suite

Many YAML libraries across different programming languages use this test suite, including:

  • C: libyaml, libfyaml
  • C++: rapidyaml
  • C#: YamlDotNet
  • D: dyaml
  • Haskell: HsYAML
  • Java: SnakeYAML Engine
  • JavaScript: yaml
  • Nim: NimYAML
  • Perl 5: YAML::PP
  • Scala: Scala-Yaml
